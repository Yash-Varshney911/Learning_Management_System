## ✨ Key Features

This application includes a complete workflow for students and administrators:

* *User Authentication:* Secure registration and login for both students and administrators.
* *Course Enrollment:* Students can browse available courses and enroll directly.
* *Notes Management:* Uploading, categorization, and retrieval of study materials/notes.
* *Administrator Portal:* Secure portal for managing users, courses, and content.

## 💻 How to Run This Project Locally

This is a key section for recruiters. It shows you understand deployment.

1.  *Clone the Repository:*
    bash
    git clone [[https://github.com/Yash-Varshney911/Learning-Management-System.git](https://github.com/Yash-Varshney911/Learning_Management_System.git)]
    
    In Terminal
    
    cd Learning-Management-System
    

3.  **Setup Virtual Environment**:
4.  
    python -m venv venv
    
    .\venv\Scripts\activate   # On Windows
    

8.  **Run Migrations**:
    
    python manage.py makemigrations

10.  **Start the Server**:
    python manage.py runserver
